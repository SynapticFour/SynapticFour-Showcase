# Procurement officer — short path

**Audience:** Procurement / purchasing / IT vendor management (not lab engineering)
**Time:** ~20–30 minutes of reading + one email
**Not this page:** deep technical evaluation → [../for-evaluators/](../for-evaluators/)

## What you need to decide

Whether Synaptic Four is worth a **time-boxed pilot conversation** for on-premise genomic / clinical-compliance infrastructure — without treating marketing claims as certificates.

| Question | Short answer | Where to verify |
|----------|--------------|-----------------|
| What are we buying? | Customer-hosted software (BUSL products) + optional support; not SaaS custody of your data | [overview.md](overview.md) · [pricing.md](pricing.md) |
| Cloud lock-in? | Designed for on-prem / sovereign deployments; customer holds keys | [key-custody.md](key-custody.md) · [co-custody.md](co-custody.md) |
| Certificates included? | **No** — technical evidence artefacts, not ISO/EHDS/MDR certificates | [legal/README.md](legal/README.md) · [compliance-framing.md](compliance-framing.md) |
| Support / uptime? | Founder-scale, business hours CET; numeric uptime SLA only if Enterprise SOW | [support-tiers.md](support-tiers.md) |
| How do we prove claims? | Re-run Showcase golden path / Evidence Pack; optional HelixTest | [evidence-pack.md](evidence-pack.md) · [../for-evaluators/](../for-evaluators/) |
| Legal pack? | NDA → Pilot → DPA/MSA via private business templates (counsel before signature) | [legal/](legal/) |
