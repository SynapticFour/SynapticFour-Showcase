# Legal pointers

This repository is an evidence pack, not a contract library. Written agreements are not published here.

Questions can be sent to [contact@synapticfour.com](mailto:contact@synapticfour.com).

## Pilot exclusions (public)

- A green fixture job or laptop golden path is not production proof.
- HELIOS reports and Evidence Packs are technical artefacts, not certificates.
- HelixTest is not GA4GH certification.
- Indicative prices are not published in this tree. Only a written quote is binding.
