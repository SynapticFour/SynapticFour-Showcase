## Pilot exclusions (always attach)

A Synaptic Four **pilot** does **not** include, unless a signed SOW says otherwise:

1. **24/7 on-call** or enterprise numeric uptime SLA
2. **MDR / IVDR / ISO 27001 / SOC 2 / EHDS certification** or certificates of compliance
3. Synaptic Four operating as **controller** of production clinical/genomic data (default: customer-operated, customer-held keys)
4. A Synaptic Four **hospital EHR UI**
5. Unlimited custom feature development
6. Kenya (or other) jurisdiction profile as **PRODUCTION legal opinion** without counsel sign-off
7. HELIOS / Evidence Packs as **auditor-accepted certificates** — they are technical evidence artefacts

See also: [evidence-pack.md](../evidence-pack.md) · [co-custody.md](../co-custody.md) · [key-custody.md](../key-custody.md)
